# Training Experiment

Ask what result could change the next decision before requesting training. For a concrete mechanism test, read [mechanism-directed training procedures](references/mechanism-directed-training-procedures.md). It retains nine adversarial/optimization designs with prerequisites, measurements and response interpretation, plus component, sampling and duration contrasts. Select a useful design rather than launching a mandatory sweep; its old packet budgets are not universal permissions. Use the execution contract's actual state preparation, controls, data and budget.

Read the shorter [diagnosis and experiment mechanics](references/diagnosis-and-experiments.md) when comparison identity, prior response or recovery interpretation is the unresolved issue. It is not a mandatory extra document for every well-defined contrast.

Define the leading explanation, a consequential alternative and observable responses that separate them. Use the cheapest adequate observation. A direct supported adjustment may be preferable to a branch; not every uncertainty deserves a trial. A cached-batch capacity check, an LR-range run and a matched continuation answer different questions.

For local attribution, match the complete starting state, relevant inputs, random state, actual exposure, schedule phase and evaluation population. Independent deserialization or tensor copies must prevent one branch mutating another's saved model or optimizer state. Same seed alone is insufficient. Distinguish evidence of matching from an intention to match.

For a whole-method comparison, allow consequential interacting settings to be treated under comparable declared resources. A joint treatment is legitimate but does not identify the effect of each scalar. For an auxiliary mechanism, an untrained starting checkpoint is not a continued-training baseline; compare permitted continued learning with and without the questioned path when that distinction matters.

Specify informative endpoints before seeing outcomes. Short early rankings can reverse; retain declared later endpoints and incomplete or null outcomes. Verify the treatment actually executed with nonzero exposure before interpreting a negative result. A numerical effect is not necessarily a semantic quality effect, particularly with unlabeled target data.

Interpret each arm relative to its start and to the other arm, retaining sample identities where legal. Equal aggregate counts can conceal different individual errors. Preserve all failure, preparation, evaluation and discarded-branch costs. Failed or confounded comparisons leave effects unknown.

Return a concrete legal experiment or response interpretation using the caller's schema. Measurement, execution, adoption and restoration are separate actions. If adoption is permitted, bind it to the actual complete resulting artifact; otherwise propose it for the owning worker. Completion means the question has an interpretable result or a clearly bounded failure, not that an arm must win.
