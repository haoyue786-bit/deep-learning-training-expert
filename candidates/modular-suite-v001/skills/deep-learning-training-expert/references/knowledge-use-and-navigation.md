## What applying a source means

Use the source at the level it supports:

- A mathematical identity can explain a quantity under its stated definitions.
- An implementation establishes behavior in its inspected version and active branch.
- An author's successful recipe is evidence in the reported model, data, schedule and evaluation setting.
- A causal interpretation or adaptation to this run requires the current facts and compatible assumptions.
- A project contract determines permissible actions and data; it does not prove a scientific mechanism.

For example, DAFormer's differentiated encoder/head rates help explain how a new decoder can learn while a useful backbone is protected. They do not justify accelerating an already trained source head simply because the task is segmentation. TTUR supports considering different opponent timescales, while its reported exceptions prevent turning D-rate > model-rate into a law.

Read the relevant section far enough to understand its prerequisites, operative method and failure cases. A headline or positive example alone can select the wrong direction. If the paper and executable code differ, use the code for the current executable semantics and keep the paper's result attached to its actual setting. Resolve disagreements by assumptions and evidence, not citation counts.

## Make the knowledge change the decision

The useful internal connection is: observed facts → compatible mechanism and alternative → action that affects that mechanism → expected task response. The outward answer can stay concise and use the caller's schema. It need not reproduce this document or a fixed reasoning template.

Prefer the most informative evidence already present. If it supports an ordinary direct adjustment, do not impose a new experiment as a procedural toll. When two mechanisms imply different actions and existing evidence cannot separate them, choose a permitted discriminating observation or contrast. Missing target labels do not prevent every action, but they limit which outcomes can honestly be called target improvement.

Illustration: source F1 declines, predicted cashew area expands, and adaptation strength recently increased. Domain-confusion loss also improves. Read the adversarial and negative-transfer mechanisms rather than concluding that either “better domain loss is good” or “expansion proves collapse.” Check the actual shared-gradient path, source class errors, supported target confusions and changed score scale. If supported errors implicate the auxiliary path, weakening that path while retaining supervised learning can be justified. If score ranking is retained and only a probability scale changed, calibration/decoding deserves consideration. If exposure or label identity changed, repair that factual problem first. Different findings imply different actions.

After acting, distinguish a mechanical response from useful task response. A smaller auxiliary gradient verifies that its control worked; it does not verify accuracy. If that response occurs but relevant errors do not improve, revise the semantic explanation instead of repeating the same scalar adjustment indefinitely.

## Preserve knowledge while keeping calls economical

Carry the current task identity, adopted state, relevant intervention/response and unresolved alternative in compact state. Retain source locations for conflicts without repeating complete logs. Reuse professional knowledge already present in a genuine continuing context; a new stateless request needs the relevant bodies again. Scripts can calculate counts, curves and identities; their outputs do not decide whether a method's assumptions hold.

Detailed references stay on disk and remain available. Do not summarize away a decisive counterexample to save tokens, and do not force every possible topic into the prompt. A successful package proves delivery of selected material; comprehension and quality remain separate from that mechanical fact.
