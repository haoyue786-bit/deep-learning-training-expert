# Professional suite composition and delivery

Install the suite as nine sibling Skill directories. The coordinating entry depends on the professional capabilities it uses, while each professional Skill includes its own necessary references and helpers. A host may also supply professional instruction text inline for a tools-disabled call. Do not assume a nested SKILL.md is automatically discovered.

Routing follows the actual question rather than a keyword-only gate. Fresh starts involve initialization; exact continuation primarily concerns restoration. Explaining an error calls for diagnosis, which can directly support adjustment. Designing a controlled contrast calls for experiment guidance. Whether to train more and which existing artifact to deliver are independent questions, even in one turn. A request solely to recover facts need not activate tuning.

Preserve one shared scientific state. A professional Skill does not create a separate run or vote. If two interpretations conflict, return to the source facts and hypotheses rather than allowing the last-loaded module to win. Task contracts determine legal execution; they do not establish scientific truth.

The delivery record should identify the exact Skill and reference bodies used. Omit duplicate identical reference bodies within one request while retaining their hashes and source paths. Do not omit a reference on a later stateless call merely because a previous call received it. Cached or persistent context is reusable only when actually present. Byte counts are not token measurements; log actual reported usage where available.

A delivery manifest proves what was packaged, not what the model understood. Test routing and scientific interpretation on real truncated histories before attributing improved training to this structure.

For tools-disabled calls, [suite_packet.py](../scripts/suite_packet.py) packages explicitly selected professional Skill entries and reference bodies from the suite directory. It deduplicates identical bodies only within that request, retaining every source path and hash. The caller still chooses relevant knowledge and must submit the resulting bodies.
