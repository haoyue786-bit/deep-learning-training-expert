# From tile evidence to a Cashew training choice

Read after the project profile when initialization or adjustment needs a tile-specific rationale. The relationships below combine general training mechanisms with the approved project knowledge. They are candidate expert reasoning, not a fitted or validated function from AEF statistics to optimal hyperparameters.

## Begin with the inherited function

Canonical Benin2019 E173 is the reference predictor, with the trained decoder/fusion state inherited in the audited A3 runtime. The residual outlets initially preserve that function. New discriminators and optimizers have their own readiness; classification and adversarial paths do not activate exactly the same coordinates. Use [component loss paths](component-loss-paths.md) and the supplied audit when those differences matter.

This means an E0 cashew expansion can be inherited behavior rather than damage caused by the latest adaptation. Conversely, a later decline may involve a new auxiliary path even if source classification remains mostly stable. Compare the actual E0/reference, adopted intervention and response on a consistent observation population before assigning a cause.

The choice of magnitude depends on the current state, active gradient paths, optimizer, schedule and previous responses. Do not fabricate a universal lambda from a source-distance number. A sensible starting choice can be the existing reference when evidence supports it; personalization lies in the mechanism and action, not in forcing different numbers.

## Use the regional prior as an expert would

The user's observation is substantive: dense cashew usually coincides with the strongest prior regions on the common WestAfrica scale. Use it to prioritize suspicious predictions and reconcile local density with the broader geography. The prior can be systematically high and still rank useful concentrations. Ranking information is different from a calibrated probability of cashew or an estimate of plantation coverage.

Use supplied common-scale distributions and regional maps, not a fresh per-tile percentile that makes every tile's top pixels equally convincing. The profile records descriptive whole-map and CIV upper tails with different scopes. A moderate prior does not prohibit cashew; a high prior does not authorize dense cashew everywhere. Missing prior is unknown. The 12-country map is also not every part of geographical WestAfrica.

Consider whether predicted canopy pixels, orchard footprint, mixed pixels and land-cover dates describe the same thing. A small continental fraction can coexist with a large local plantation fraction. Do not enforce an invented continental area quota. External forest and wetland context supplies competing explanations; neither is an output class in this four-class model.

## Automatic negatives: a separate, reversible learning route

The user authorized an Agent-selected pool from training samples, using original source-cashew AEF discrepancy, increasing cashew probability and prior/context as soft evidence. There is no required geographic distribution, fixed patch-count ceiling, mandatory high-probability cutoff or requirement for explicit non-cashew support. A selected patch is a weak hypothesis, not a new human label.

Distance needs the actual representation and definition. Euclidean distance, cosine similarity and one-minus-cosine have different scales; even the latter need not have maximum one unless the representation/definition imposes it. Compare to relevant source-cashew and alternative distributions when available instead of treating an isolated 0.566 as a calibrated probability or universal boundary. AEF has 64 embedding dimensions, not 64 optical bands.

Keep this route separate from human positives and the fixed source objective. A low per-sample weight can still create a large total pressure if many pixels, frequent resampling or a high occurrence rate accumulate. Track active weighted contribution and exposure together with selected count. A growing pool can increase diversity or repeat the same woody confusion; those are different effects.

Use available error support to interpret its response. Reducing supported woody false positives while retaining supported positives is useful evidence. Reducing area alone is not. If suppression loses credible positives or degrades source semantics, reduce/reverse the implicated pressure, quarantine questionable candidates or recover through the advertised mechanism. An executor that cannot adopt a new loss route cannot gain that capability solely from this knowledge text.

## Learn from actual historical contradictions

Read [historical intervention cases](historical-intervention-cases.md) when the choice relies on lambda, main LR, D cadence or temperature having a predictable area effect. The retained cases show lower lambda with more expansion, lower main LR with less motion but a higher gradient ratio, a distinct cadence response and a nearly null temperature response.

These cases motivate better questions; their old supplementary data and 32-step horizons do not establish the best initializer for a newly corrected Nigeria, Senegal or CIV tile. Updated paired-year point IDs and label versions matter to quality comparisons. Do not merge two years of the same geography into apparently independent evidence or infer current accuracy from an old label set.
