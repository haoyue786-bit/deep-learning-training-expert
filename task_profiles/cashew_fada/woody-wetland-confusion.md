# Approved woody-vegetation and wetland confusion guidance

Use when the packet supplies woody_wetland_confusion_expert_v1 or evidence makes this confusion relevant. This project guidance is the approved confusion section migrated from the maintained Cashew Skill. It does not change the current packet’s actions, label access, initialization, source weights or training cap.

Treat Cashew confusion with mixed woody vegetation and wetland landscapes as a user-reported mechanism hypothesis. Locate the suspect regions and examine supplied Class2 versus Class1 competition, temporal probability/prediction changes, original source Cashew AEF distance, human-labelled errors and whole-WestAfrica prior reliability together. This worker has four classes (other crops, mixed trees/grassland, Cashew, built-up); there is no wetland output class. A wetland map supplies external context, never a measured model wetland posterior. AEF embeddings are not optical spectral bands; do not claim access to texture, radar or seasonal image evidence unless it is actually supplied.

Woody orchards and natural forest can be spectrally similar [1]. ESA WorldCover tree cover includes plantations and flooded tree cover [2], so tree cover alone cannot assign not-Cashew. Cashew agronomic guidance advises avoiding waterlogged soils [3]; persistent inundation paired with dense Cashew predictions warrants investigation, while uncertain external maps, mixed pixels, dates and local exceptions prevent automatic absence labels. These sources support hypotheses, not this model's validated errors.

Distinguish incorrect class-conditioned domain alignment from ordinary woody-vegetation ambiguity, insufficient human supervision and a prior/reference-map mistake. Use the evidence to choose an informative permitted action, rather than mechanically reducing lambda or increasing negatives. When conditioning is implicated, temperature and confidence_cap are candidate controls; when adversarial pressure is implicated, lambda_adv or discriminator LR/steps may be useful. No fixed direction is guaranteed. In this implementation softmax(logits/temperature) is clipped at confidence_cap without renormalization; temperature is not the delivered-map Cashew threshold. Main LR changes update size, not semantic correctness. Keep source initialization/class weights fixed.

Compare an unchanged arm with an interpretable permitted treatment from the same state, batches/RNG and horizon when a useful contrast is needed. Alternatively make a bounded reversible ordinary adjustment with a stated mechanism, predicted response and reversal condition, then evaluate it at the next review. Targeted separate weak automatic negatives may use the user-authorized soft source-distance/rising-probability/prior evidence without requiring a non-Cashew prototype, high probability, geographic quota or fixed patch count. A forest/wetland label alone is insufficient. Track actual exposed samples and dose, supported heldout negative FP, real positive retention, source validation and gradient/domain response; reduced mapped area alone is not success. If suppression loses supported Cashew or sustained source degradation appears, reduce/reverse the implicated pressure, quarantine suspect automatic candidates or use the advertised recovery/selection route as justified.

For jobs carrying user_prior_observation_v1, investigating supported user-reported overprediction does not require crossing historical15/25/40% area warning tiers. Prior quantiles and rough regional prevalence remain descriptive reasoning aids, not forced decisions. The Agent may choose KEEP, a useful adjustment, an advertised experiment, STOP and a supported checkpoint within the actual packet controls.
