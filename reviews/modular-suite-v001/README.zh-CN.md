# 模块化训练专家 Skill：中文候选审阅版

**状态：供人工审核的候选设计与指令说明，尚未通过完整训练效果验收。不是 v028 正式发布版。**

本页集中说明当前九项 Skill 的结构、职责和判断内容。Skill 名称及程序字段保留英文，便于与实现对照；本页不是可直接安装的全量中文代码包。详细参考文档和确定性脚本不在这里逐字翻译。正式英文版暂不替换。

## 先看整体结构

```text
deep-learning-training-expert           总控训练专家
 ├─ training-fact-reconstruction        理解真实训练事实
 ├─ training-initialization             选择初始化与起点
 ├─ training-diagnosis                  诊断异常及原因
 ├─ training-adjustment                 调整训练或保持设置
 ├─ training-experiment                 设计和解释必要实验
 ├─ training-stop                       判断是否继续训练
 ├─ training-checkpoint-selection       选择已有模型
 └─ training-experience-update          更新有条件的经验

Cashew 领域资料：模型／类别／样本／prior／实际执行合同
```

这是一个整体套件，内部能力也可单独使用。默认由同一个 Agent 持续负责同一条训练，根据当前问题读取相关 Skill。拆成九项，不意味着每次启动九个 Agent、调用九次模型，或每轮按顺序走完九个步骤。

结构参考 [Scientific Agent Skills 项目](https://github.com/K-Dense-AI/scientific-agent-skills)及[对应论文](https://arxiv.org/html/2609.00065v2)：每项能力有清晰边界，详细知识按需读取。该论文没有证明安装这些 Skill 就能提高真实训练精度；我们的套件也需要独立验证。

## 1. 总控训练专家

**名称：`deep-learning-training-expert`**

目标是改善实际部署需要的模型。精度、得到有效响应的时间、全部成本分别报告，不能把其中一项自动当作另一项。

首先理解任务目标、允许的数据与监督、模型组件、当前状态，以及执行器允许的动作。科学判断与实际执行、采用实验状态、发布结果分开。

根据问题使用专业能力：

- 日志不熟悉、指标冲突：先恢复事实。
- 新训练或迁移起点：选择初始化。
- 异常、错误或干预失败：诊断；必要时结合调整。
- 有必要区分原因：设计实验，而非自动扫参数。
- 是否值得再训练：判断继续或停止。
- 应该交付哪个已有模型：独立选模。
- 已有真实反馈：更新条件经验。

正常训练复核可能只需要理解最近响应并决定下一观察窗口。只问事实时，回答事实即可。缺少某项能力时应说明，不能假装调用了不存在的 Skill。

始终保持同一条科学线索：区分继承与新建组件、提出的改动、实际执行的更新、已采用状态及后续响应。不能用相似类名、附近字段或某个 epoch 代替真正需要的事实。

每次重要决定解释：当前证据为什么支持该选择，最有意义的替代解释是什么。合理的基准设置或 KEEP 都有效；数值不同不代表个性化。代理量按预期变化，不代表实际任务更准确。

干预失败后，应修改不成立的解释。反转一个参数、恢复完整 checkpoint、在当前状态继续，会保留不同的训练进展和优化器历史。诊断、分支、失败、丢弃和重放的工作都计入成本。

STOP 与 SELECT 分开：短期平台可能恢复，但预算还多也不是继续到上限的理由；停下来的最后模型不自动成为交付模型。

### 减少不必要的 token

只传相关事实及知识，保留来源和重要历史。指标计算、身份及格式检查由确定性工具完成；不反复传完整日志，不每轮审查全部模块，不默认加一个付费评审 Agent。

上下文压缩或切换时，保留任务版本、实际状态、有效设置、关键干预及响应、未解决解释、证据截止时间。记录上下文变化，不能声称新线程还是原线程。只有输入身份确实相同、完成收据已核实的结果才可复用。

遵循调用方的真实输出格式、合法动作组合和 artifact ID。收到不确定的完成状态先对账，不盲目重试；保留格式拒答和费用，不手工改成成功答案。

## 2. 训练事实理解

**名称：`training-fact-reconstruction`**

回答“这些日志究竟证明了什么”，不自动做调参决定。

恢复与当前问题有关的任务、数据、标签、模型状态和实际训练暴露。每项重要指标对应到：样本范围、类别、统计量、单位、评价模式、观测时间和产生它的模型状态。

区分三种证据：原记录明确报告的、由所给代码推断的、已核验在历史运行中发生的。缺测是未知；关闭损失后的零值不代表测到了零梯度。

依次辨别观测、提议、执行、采用、响应。epoch 不是数组下标；选中的 epoch 不是最后训练的 epoch；当前代码不能悄悄重新定义历史指标。发现冲突时尽量回到原记录，无法解决的部分明确限制，不让一个冲突抹掉所有可用事实。

调用方提供证据注册表或 JSON 指针时，使用确切位置。脚本可核对原始值和身份，但无法证明因果解释正确。格式合法的答案仍可能把指标理解错。

输出所需事实、来源、时序、冲突和未知。只问事实时到此为止；正常科学判断则把必要事实带入推理，不强制增设一套执行协议。

## 3. 初始化专家

**名称：`training-initialization`**

选择合理的完整训练起点，而非为了“个性化”给每个数据集发一组不同数字。精确续训优先恢复原状态；重新初始化属于另一项处理。

### 什么确实需要学习

检查继承参数、新组件、实际损失路径、优化器参数组、归一化缓冲区及调度器。预训练编码器不等于头已训练；加载了 checkpoint 也不等于头是随机的。这个区别会改变选择时，应核对真实加载和依赖证据。

为继承组件采用较小移动、给新组件不同学习速度可以是合理假设，但倍率和方向需要当前任务证据。不能把随机头的配方自动用在已经训练的 decoder 上。

### 哪种观察能改变初始化选择

初始损失或输出异常时，先依据真实损失、采样、类别权重和继承预测器判断预期。`log(C)` 不是预训练或加权分类器的通用初始损失。按照类别频率设置偏置，可能适合某些新头，也可能覆盖已有头的有用校准。

用梯度尺度选学习率时，注意 Adam 历史、裁剪、权重衰减及接近零的参数会改变“梯度→实际更新”的关系。LR-range 测试同时改变训练状态和学习率，不是多次同起点因果对照；除非明确采用，否则应恢复完整起点。

缓存批次拟合可检查实现或组件容量，不证明泛化，也不证明对抗信号语义正确。允许准备状态时，区分真正采用的 warm start 与做完丢弃的探针，准备成本全部计入。

输出完整起点、合法初值或参数组／调度选择、当前理由、预期早期响应和关键未知。执行器不支持的准备只能作为建议。完成不等于证明了最优初始化。

## 4. 诊断专家

**名称：`training-diagnosis`**

从实际症状及最近变化开始，判断下一步最需要区分什么。

输入损坏、标签映射、采样、损失实现、归一化模式和实际更新都可能解释异常，不能把它们统一叫作“学习率不好”。坏批次和过大 LR 都可能造成尖峰，但处理不同；裁剪后不再 NaN，不代表语义问题修好了。

区分拟合、排序、概率校准与实际输出规则。最佳阈值更高不能单独证明训练轮次不足，需要结合合法的排序能力、分数尺度及匹配续训证据。负样本面板能测误报，不能证明召回保留；地图面积变化也不是实测精度。

多损失系统要定位共享参数和实际仍活跃的路径。loss 大小、梯度范数、加权梯度比和优化器位移不同。梯度方向冲突可支持调查，不自动证明目标负迁移。暂停一项损失仍有错误时，应调查剩余损失、归一化和模型更新，而不是反复调整已停用机制。

围绕重要的主要解释，给出能导向不同动作的替代解释，以及可区分二者的观察。不需要列全世界所有原因；简单、可逆且证据充分时可以直接干预。若同时改多个参数，只能把响应归给组合。

反证出现后，说明究竟是哪部分失败：事实前提、机制解释、数值选择或响应时间。不能把每个混合结果永久写成“部分支持”。

## 5. 调整专家

**名称：`training-adjustment`**

基于当前诊断，选择可执行改动或 KEEP。

### 参数与机制的联系

过大的实际更新可以支持减小 LR、warmup 或裁剪，但它们作用不同。训练拟合弱也可能是暴露不足、梯度中断、输入错误或正则过强。降低 LR 可以减慢记忆，却不一定修复泛化。WD、dropout、梯度惩罚和归一化作用对象不同。

检查有效学习率、参数组及调度阶段。batch 与梯度累积影响噪声、暴露和更新频率，不能盲用线性缩放。继承组件和新信号组件可能需要不同策略，但方向要有证据。

对抗训练要辨别：D 学习速度、过拟合、类别条件、模型侧压力还是语义不匹配？D 学习率与更新次数影响不同的暴露和成本。降低对抗系数可以减小运动却不修正错误；更强 D 也可能强化错误信号。域混淆不代表适配良好。

### 决定后怎样判断

说明当前状态为什么支持这个动作而非替代动作。数值可以是有依据的一小步或参考，不应冒充已发现的最优值。没有必要为展示个性化强改参数，也不默认开网格或额外分支。

按机制和调度确定观察窗口。中间的 KEEP 不能覆盖上次实际干预的记录。质量、分类错误、数值和源域安全分别看。预期响应未出现时，重新考虑原因与时间，而不是持续调整一个容易推动代理量的旋钮。

反转参数、完整回滚和修复后续训保留不同历史；比较恢复可能与回滚代价，短期退步不代表不可逆。必要安全退出仍然有效。

只输出实际允许的控制和动作；架构改造或未开放损失不是普通标量调参。请求实验不自动授权采用该分支。

## 6. 实验专家

**名称：`training-experiment`**

训练前先问：哪个结果会改变下一步决定？

明确主要解释、重要替代解释及区分它们的可观测响应。选择足够且便宜的证据。直接合理调整可能优于开分支；不是所有未知都值得实验。缓存容量检查、LR-range 测试、同起点续训回答不同问题。

局部归因时，匹配完整起点、输入、随机状态、真实暴露、调度和评价范围。独立反序列化或拷贝模型／优化器状态，防止一个分支改掉另一分支的起点。同 seed 不够。声称匹配、记录匹配、验证匹配要分开。

比较整套方法时，应给相关交互设置可比的处理权限和预算。组合处理合法，但不能归因到单一参数。证明辅助机制的作用时，未训练的起始 checkpoint 不是继续训练基线。

在看到结果前定义端点。短时排序可能反转，后续端点、空效应和失败都保留。先确认处理真的执行且有有效暴露。数值变化不自动是语义收益，尤其在目标无标签时。

每个分支相对起点、相对另一分支都要解释。样本身份可用时保留逐点变化，不能把相同混淆计数当成相同错误点。准备、评价、失败、丢弃分支全部计费。

输出合法实验或解释。测量、执行、采用和恢复是不同动作；是否采用要绑定真实完整状态。实验完成可以是有解释的失败，不要求一定有获胜分支。

## 7. STOP 专家

**名称：`training-stop`**

依据任务目标，判断下一段训练的价值。读取最近响应、前次干预、实际优化器更新、有效调度和剩余预算。

### 平台究竟意味着什么

先比较同一指标和样本范围。验证交叉熵上升而 accuracy 改善，可能是置信度变化；总体改善也可能掩盖某类退化。使用明确的主要目标及错误切片，不能悄悄改成更平滑的代理量。

通过真实更新和阶段理解 epoch。warmup、刚降 LR、新组件适应或目标切换，都可能使短平台证据不足。更新变小也会改变观察响应所需暴露。继续时要有具体的可能收益及有信息的观察窗口，不能永远以“也许晚点变好”为理由。

确认过拟合或语义伤害时，指出实际测量与样本。更多 epoch 不能修复标签映射错误。无标签熵、地图密度、域混淆不能单独证明目标质量变坏，也不能证明后续不可能恢复。

### 比较真实可行的机会

考虑再训练一段、已有依据的调整或低成本观察是否可能改变可用结果。继续不必每次额外试验；停止不必等所有理想指标。预算退出与收敛分开。

不设通用 patience、最低 epoch 或跑满规则。Karpathy 与 FSDL 对早停优先级存在不同建议，应结合当前情境，而不是通过“文献多数票”决定。

输出继续、停止或合同允许的暂停，交代证据、最强替代选择及响应时机。停止依据要区分科学进展、实测伤害、安全和资源。不自动选择交付模型，保留可恢复状态。

事后固定基线更晚的改善可以揭示早停错误，但不能倒灌为当时的判断依据。

## 8. SELECT 专家

**名称：`training-checkpoint-selection`**

在真实、合法、已有的 artifact 中选择。训练终止不自动选择最后一个模型。

确认每个模型真正包含的状态及每项观察的来源。缺失评价是未知而不是零。比较最强替代项，必要时包括早期有效阶段或恢复状态，不能只看摘要重点列出的候选。

有合法验证真值时，按目标指标、相关类别错误、不确定性与样本依赖判断。accuracy、F1、交叉熵和校准不是同一个目标；不能编一个综合分掩盖取舍。

目标质量不可测时，源保留、分布稳定、熵与域混淆只能提供有限证据。地图符合弱 prior 不等于精度提高。遵循明确的回退规则；若没有，提出并标明暂定依据，与最强替代项比较。

### 模型与阈值分开

说明采用固定阈值还是合法拟合的阈值策略。阈值更高不单独证明训练不足、排序更差或泛化更好。阈值只能在授权选择数据上拟合，最终评估保持独立；校准工作计入成本。

若部署目标涉及召回或误报限制，比较对应证据。负样本面板不能证明召回。稀疏、相关或反复看过的样本限制结论可信度。

输出确切 artifact、选择标准、最强替代项和局限。推理权重可能不够续训，后者需相应优化器、调度、组件、归一化和 RNG 状态。选择冻结后才能打开最终测试；事后 oracle 最优只能评价遗憾，不能指导过去的 SELECT。

## 9. 经验更新专家

**名称：`training-experience-update`**

通过修正最小的不可靠主张，改善后续判断。

区分观察、匹配干预效果与机制推断。记录任务／组件／数据身份、合法指标、当时可见状态、真正执行的改动、暴露、响应窗口、替代解释、成本及适用条件。可以用简短文字，不需要另建复杂记忆服务。

保留 KEEP、空效应、负效果、失败和不完整结果。梯度比改变而错误未改善，只能产生机械效果经验。相同位置的不同年份或种子不是独立地理任务。标签修订推翻结果时限制或撤回对应结论，保留旧记录。

迁移经验时解释机制为什么相似、哪些条件不同。相似特征距离或地理位置不证明共享最优参数。历史赢家可能来自额外预算、重复选择或当时不可见信息。

知识更新需在允许范围内版本化，保留来源。不能自动重写冻结 Skill、活动实验或生产调用方；提议经验可以保持未证实。经验记下来不代表经验检索已经改善训练。

## 10. Cashew 领域知识

以下属于项目约定，不伪装成通用深度学习规律：

- 类别顺序为 0 其它农作物、1 混合树草、2 腰果、3 建成区，10 忽略；腰果是 Class2。
- canonical 起点为 Benin2019 E173，源域 CE 类别权重保持 `[3,3,10,3]`。已审计的组件并非只有编码器继承，不能默认把 decoder 当随机头重置。
- AEF 的 64 维是嵌入特征，不是 64 个光谱波段。源域特征距离可以支持解释，不能直接确定类别或最优超参。
- 正样本采用已确认的 `cashew.kmz`；跨年同位置 ID 与最新修订标签须核实。
- prior 的高值反映相对适宜／密集种植线索，不是校准概率。非高值区域预测腰果过密值得检查，结合整个西非背景、混交林／湿地、源特征与训练响应判断，不设硬面积配额。
- 自动负样本是独立、低权重、可撤销的弱监督机制。结合原源域腰果 AEF 距离、p2 变化和 prior 综合判断；不恢复机械高概率门槛、地理配额或样本数量上限。人工、自动及评价样本不得混用。
- 源验证、目标 DEV、最终评价、人工训练补样和 Planet 弱证据各自有权限和作用，不相互替代。
- 某种 conditioning temperature 不自动等于预测阈值；暂停对抗不一定停掉归一化或其它损失路径。

|端到端检查与单批拟合|Karpathy、CS231n、FSDL|单批拟合成功就证明泛化正确|
|初始化及组件分组|Swin、DAFormer、实际加载审计|头永远随机、头 LR 永远某倍率|
|LR、warmup、clip、正则与 batch|Google Tuning Playbook、Smith|一个默认方向适合所有优化器和任务|
|对抗动态和类别条件|TTUR、FADA、DANN、CDAN|D 越强越好，域混淆就是精度提高|
|负迁移与伪标签|SENTRY、label-shift 研究、DAFormer|高置信度伪标签必然正确|
|多损失和梯度冲突|GradNorm、PCGrad及实际损失路径|某个梯度比就是最优控制目标|
|早期曲线、停止和选择|Playbook、曲线／预算研究及真实反例|短跑排名就是长期排名|
|历史经验|TNP、Reflexion、ExpeL等|检索相似案例就是可靠参数迁移|

参考资料必须给出条件、机制、区分证据、反例和原文定位。不能只写“观察—假设—实验—反馈”，也不能把整个文献库每次塞进模型。
